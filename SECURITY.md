# Security Policy

## Supported versions

The latest GitHub release is supported.

## Reporting

Please use GitHub's private security advisory flow. Do not publish sensitive repository names, commit subjects, remote URLs, credentials, or private paths in an issue.

## Boundary

BranchRadar reads local Git metadata and prints it locally. It performs no network request or mutation. JSON and terminal output can include branch names, upstream names, and commit subjects; review and redact output before sharing it.
